# Настройка отправки заявок с сайта

## Текущая реализация

Сейчас формы отправляют заявки на email через сервис **FormSubmit.co** (бесплатно, без регистрации).

### Что нужно сделать:

1. Откройте файл `src/components/Modals.tsx`
2. Найдите строку:
   ```javascript
   await fetch('https://formsubmit.co/ajax/YOUR_EMAIL@example.com', {
   ```
3. Замените `YOUR_EMAIL@example.com` на реальный email клиента

**Важно:** При первой отправке FormSubmit пришлёт письмо с подтверждением — нужно перейти по ссылке в письме. После этого все заявки будут приходить на этот email.

## Альтернативные варианты (российские сервисы)

### Вариант 1: Яндекс.Формы (рекомендую)

**Плюсы:**
- Бесплатно (до 1000 ответов/мес)
- Российский сервис
- Можно встроить на сайт
- Заявки приходят на email + хранятся в Яндекс.Диске

**Как настроить:**
1. Зайти на https://forms.yandex.ru
2. Создать форму (поля: имя, телефон, комментарий)
3. Скопировать ID формы
4. Встроить через iframe или использовать API

**Интеграция с сайтом:**
```javascript
// Вместо FormSubmit использовать отправку на Яндекс.Формы
const response = await fetch('https://forms.yandex.ru/api/v2/forms/FORM_ID/answers/', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    fields: {
      'Имя': name,
      'Телефон': phone,
      'Комментарий': comment
    }
  })
});
```

### Вариант 2: Telegram-бот

**Плюсы:**
- Бесплатно
- Заявки приходят прямо в Telegram
- Мгновенные уведомления

**Как настроить:**
1. Создать бота через @BotFather в Telegram
2. Получить токен бота
3. Получить chat_id (через @userinfobot)
4. Отправлять заявки через API Telegram

**Интеграция с сайтом:**
```javascript
const BOT_TOKEN = 'YOUR_BOT_TOKEN';
const CHAT_ID = 'YOUR_CHAT_ID';

const message = `🔔 Новая заявка с сайта H2O-Про\n\n` +
                `📋 Тип: ${config.title}\n` +
                `👤 Имя: ${name}\n` +
                `📞 Телефон: ${phone}\n` +
                `💬 Комментарий: ${comment || 'не указан'}`;

await fetch(`https://api.telegram.org/bot${BOT_TOKEN}/sendMessage`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    chat_id: CHAT_ID,
    text: message,
    parse_mode: 'HTML'
  })
});
```

## Рекомендация

**Для простоты и надёжности рекомендую:**

## Как посмотреть сайт

Сайт уже собран и готов к просмотру!

### Вариант 1: Открыть локально

1. После сборки (`npm run build`) создаётся папка `dist/`
2. Откройте файл `dist/index.html` в браузере

**Но:** из-за ограничений безопасности браузеров, некоторые функции (отправка форм) могут не работать при открытии локально.

### Вариант 2: Запустить локальный сервер

```bash
npm run preview
```

Откроется сайт на `http://localhost:4173`

### Вариант 3: Загрузить на хостинг

Загрузите содержимое папки `dist/` на любой хостинг:
- **Netlify** (бесплатно) — просто перетащите папку
- **Vercel** (бесплатно)
- **GitHub Pages** (бесплатно)
- Любой платный хостинг (Timeweb, Beget, Reg.ru)

### Вариант 4: Я могу показать

Если у вас есть доступ к файлам проекта, откройте `dist/index.html` в браузере.
